Controls

What stakeholders can rely on, and how strongly each guarantee is enforced.

Automated
CI blocks it. A pipeline check fails the build or the phase gate.
Gate-checked
A gate verifies the evidence exists (an approval, a record, a decision). A person provides it.
Review
Reviewers check it against a written checklist. Findings block the merge by severity.
Process
A playbook rule every agent and person follows. It's not mechanically enforced.

Coding standards

Every rule has an id that reviews cite. MUST rules are mandatory, and an exception needs a recorded architecture decision. SHOULD rules are expected, and skipping one needs a stated reason.
