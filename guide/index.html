Skills & roles

Playbooks live in .adlc/skills/ and run in any agent: type /adlc-<x> or say “run the <x> phase”. Reviewer roles in .adlc/roles/ always run in an independent context.

Traceability

Every artifact traces to ids in SPEC.md, forwards and backwards. The gates enforce it; make trace writes the matrix.

Charter goal→ FR / NFRrequirement→ ACacceptance criterion→ TestAC id in the name→ JUnit result

FRs also map to design components, and feedback items reference the FR/AC ids they concern. The backward direction checks that every test, component and feedback item points at a real requirement.
